# Aaron user guide

Aaron is a Markdown editor for macOS 26 or later, made for writing blog posts.
It has a live preview, AI-assisted review that never changes your text without
your approval, and extra help for [Pelican](https://getpelican.com/) blogs.
None of these depend on where your files or tools are: everything is set up in
Settings.

- [Getting started](getting-started.md): install, first launch, the window
- [Writing and editing](editing.md): documents, highlighting, status bar, find and spelling
- [Preview](preview.md): the preview panel, built-in and external renderers
- [AI review](review.md): running AI actions and working through suggestions
- [Setting up AI actions and providers](ai-setup.md): prompts, Claude, Codex, web search
- [Pelican support](pelican.md): metadata, tag completion, new posts
- [Settings and the configuration file](settings.md): every option
- [Keyboard shortcuts](keyboard-shortcuts.md)
- [Troubleshooting](troubleshooting.md)
- [Example: setting up a Pelican blog](example-blog-setup.md)
