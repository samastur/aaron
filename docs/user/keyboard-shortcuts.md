# Keyboard shortcuts

| Shortcut | Command | Menu |
|---|---|---|
| ⌘N | New document | File |
| ⌥⌘N | New Pelican post | File |
| ⌘O | Open | File |
| ⌘S | Save | File |
| ⌘, | Settings | Aaron |
| ⇧⌘M | Markdown Help | Help |
| ⌥⌘E | Show/Hide Editor | View |
| ⌥⌘P | Show/Hide Preview | View |
| ⇧⌘R | Refresh Preview | View |
| ⌥⌘R | Show/Hide Review | View |
| ⌥⌘1 … ⌥⌘9 | Run the first nine AI actions | Review |
| ⌘. | Cancel the running AI action | Review |
| ⌥⌘] | Next suggestion | Review |
| ⌥⌘[ | Previous suggestion | Review |
| ⌥⌘↩ | Accept the selected suggestion | Review |
| ⌥⌘⌫ | Dismiss the selected suggestion | Review |
| Esc, ⌥Esc | Complete the word or, on the `Tags:` line, the tag | |
| ⌘F, ⌥⌘F | Find, Find and Replace | Edit ▸ Find |
| ⌘G, ⇧⌘G | Find next, previous | Edit ▸ Find |
| ⌘Z, ⇧⌘Z | Undo, Redo | Edit |

**Edit ▸ Refresh Pelican Tags** and **Review ▸ Clear Suggestions** have no
shortcut.
